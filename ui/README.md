# Bedrock++ UI

This directory is reserved for original Bedrock++ UI resource-pack definitions.

## Current status

Planning and reference research only. No custom UI screen implementation has been validated in Minecraft yet.

## Rules

- Use the `bedrock_plus_plus` namespace for project-owned UI definitions.
- Do not copy code or textures from Déesse UI or other packs.
- Add only screens and controls confirmed to be exposed to supported resource-pack customization.
- Keep reusable components separate from screen-specific definitions.
- Record target Minecraft versions and test results in the documentation.

See [UI research](../docs/UI_RESEARCH.md) and [UI design plan](../docs/UI_DESIGN.md).
