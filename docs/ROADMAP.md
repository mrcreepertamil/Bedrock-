# Roadmap

This is a planning document, not a promise that every idea will ship. Priorities may change after technical research and in-game testing.

## Phase 0 — Foundations
- [x] Create the private repository.
- [x] Establish project direction and proprietary status.
- [ ] Choose the initial toolchain and project layout.
- [ ] Record the minimum supported Minecraft Bedrock version.
- [ ] Set up a repeatable local test world and release process.

## Phase 1 — Research and prototypes
- [ ] Map which Bedrock UI surfaces can be customized reliably.
- [ ] Prototype a small, maintainable UI improvement.
- [ ] Research replay capture and playback constraints on Bedrock.
- [ ] Test camera-control and cinematic workflow possibilities.
- [ ] Document platform limitations and performance considerations.

## Phase 2 — First usable features
- [ ] Select a small set of feasible features.
- [ ] Implement and test each feature independently.
- [ ] Add installation and compatibility documentation.
- [ ] Prepare a private test release.

## Longer-term ideas
- More interface and quality-of-life improvements.
- Replay and cinematic creation tools inspired by Java mod workflows.
- Scene, camera, and actor tooling where Bedrock APIs allow it.
- Additional vanilla-style enhancements as the project evolves.

## Out of scope for the current direction
- Mob AI or mob behaviour overhauls.
- Changes that unnecessarily turn the project into a different game.
