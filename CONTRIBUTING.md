# Contributing

Bedrock- is currently a private project.

Do not share repository contents, screenshots of private source, builds, credentials, or unreleased plans outside the project without the owner's permission.

Before implementing a feature:
1. Describe the player-facing goal.
2. Research whether the required behaviour is supported by Minecraft Bedrock.
3. Propose the smallest testable prototype.
4. Record supported game versions and known limitations.
5. Test in a separate development world before merging changes.

Keep changes focused and avoid adding dependencies until there is a clear need. Never commit access tokens, passwords, private keys, or personal environment files.
