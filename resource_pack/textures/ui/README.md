# Bedrock++ UI textures

Original purple-themed PNG assets generated for the Bedrock++ resource pack.

These are original project assets, not extracted from or copied from Minecraft's Ore UI texture files.

## Files
- panel_background.png — panel surface
- button_normal.png, button_hover.png, button_pressed.png — button states
- toggle_off.png, toggle_on.png — toggle states
- slider_track.png, slider_thumb.png — slider parts
- icon_play.png, icon_realms.png, icon_settings.png, icon_worlds.png, icon_close.png — menu icons

All assets use transparent PNG where appropriate.
